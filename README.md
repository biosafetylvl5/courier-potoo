## Overview

A simple web-app demo for Courier!

`courier-potoo` demonstrates the processing of incoming files by interpolating randomly generated images into photos of potoos, then concatenating all
intermediary steps into a fun GIF. 

This workflow is done using Courier, which watches for incoming images generated by `potoo.py`'s writer service. When a file is detected by Courier, it sends the file
out to be processed into a GIF by `potoo.py`'s ingest service, using Courier's in-memory transport (no external broker or database required). The resulting GIF is saved
to `gif_dir/`. The Go+HTMX web app reads `output_dir/` and `gif_dir/` directly: an image is marked as processed once its GIF exists, which is a fun way to view the
jobs in real-time!

## Steps to Run 
1. Clone this repo and `cd` into it
2. Run `mkdir potoo/output_dir potoo/gif_dir`
3. Create and activate a python virtual environment using `python3 -m venv .venv` or `uv venv`, then `source .venv/bin/activate`. Install all requirements with `pip3 install -r requirements.txt` or `uv pip install -r requirements.txt`
4. Pull and run all docker services with `docker compose up -d`
5. View the web page on `localhost:8080`
6. Start writing files with this command:
   `python3 potoo.py -w True -o output_dir/`
7. Click on individual images to see their generated GIFs. Tiles with green backgrounds are ready to view!
