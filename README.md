## Overview

A simple web-app demo for Courier!

`courier-potoo` demonstrates the processing of incoming files by interpolating randomly generated images into photos of potoos, then concatenating all
intermediary steps into a fun GIF. 

This workflow is done using Courier, which watches for incoming images generated by `potoo.py`'s writer service. When a file is detected by Courier, one services uploads its
base64 encoding to a Redis server while the other sends the file out to be processed into a GIF by `potoo.py`'s ingest service. The resulting GIF is saved as a local file,
and the Redis instance is marked as processed. This is all caught by the Go+HTMX web app, which is a fun way to view the jobs in real-time!

## Steps to Run 
1. Clone this repo and `cd` into it
2. Pull and run all docker services with `docker compose up -d`
3. View the web page on `localhost:8080`
4. Start writing files with this command:
   `python3 potoo.py -w True -o output_dir/`
5. Click on individual images to see their generated GIFs. Tiles with green backgrounds are ready to view!
